# LYFE — деплой на сервер

Переносим проект с макбука на сервер, чтобы бот работал круглосуточно, а сканер
на входе получил HTTPS и заработала камера.

**Стоимость: около 5 евро в месяц.** Домен можно взять бесплатный.

Время на всё — примерно час, если не торопиться.

---

## 1. Что покупаем

### Сервер

**Hetzner Cloud**, тариф **CX22** — 2 ядра, 4 ГБ памяти, 40 ГБ диска, около
**4,5 евро в месяц**. Локация Nuremberg или Falkenstein: близко к Словакии,
задержка минимальная.

Этого с большим запасом хватит на несколько тысяч пользователей. Брать дороже
сейчас незачем — тариф меняется в пару кликов, если понадобится.

При создании выбери **Ubuntu 24.04** и обязательно добавь **SSH-ключ**, а не
пароль. Если ключа нет, создай на макбуке:

```bash
ssh-keygen -t ed25519 -C "lyfe"
cat ~/.ssh/id_ed25519.pub
```

Содержимое второй команды вставляешь в Hetzner при создании сервера.

### Домен

Нужен, потому что **камера в браузере работает только по HTTPS**, а сертификат
выдаётся только на настоящее имя. Два варианта.

**Бесплатно.** Заходишь на duckdns.org, логинишься через GitHub, создаёшь
поддомен вроде `lyfeparty.duckdns.org` и указываешь IP сервера. Работает
полноценно, сертификат выдаётся. Гости этот адрес не видят — он только для
твоих трёх экранов.

**За деньги, около 1–10 евро в год.** Любой регистратор, домен вида
`lyfeparty.sk` или `.xyz`. Имеет смысл, если позже захочешь публичные ссылки
и почту на своём домене.

Начни с бесплатного. Переехать на купленный — это поменять одну строку.

## 2. Первый вход на сервер

С макбука:

```bash
ssh root@IP_СЕРВЕРА
```

IP берёшь из панели Hetzner. Первый раз спросит про отпечаток — отвечай `yes`.

### Базовая защита

```bash
apt update && apt upgrade -y
ufw allow 22
ufw allow 80
ufw allow 443
ufw --force enable
```

Открыты только три порта: SSH, HTTP и HTTPS. База и приложение наружу не
смотрят вообще.

### Docker

```bash
curl -fsSL https://get.docker.com | sh
docker --version
```

## 3. Загружаем проект

Если код уже в приватном репозитории на GitHub — самый простой путь:

```bash
mkdir -p /opt && cd /opt
git clone https://github.com/ТВОЙ_ЛОГИН/lyfe.git
cd lyfe
```

Для приватного репозитория GitHub попросит логин и токен — тот же personal
access token, что и при первом пуше.

**Если репозитория нет**, залей с макбука прямо файлами:

```bash
rsync -av --exclude '.venv/' --exclude '.env' --exclude '__pycache__' \
  ~/Desktop/lyfe/ root@IP_СЕРВЕРА:/opt/lyfe/
```

Обрати внимание: `migrations/versions/` здесь **не исключаем** — на сервере
файлы миграций обязательны.

### Убираем dev-файл

```bash
cd /opt/lyfe
rm -f docker-compose.override.yml
```

Это важно. Он монтирует исходники и публикует порты — на сервере ему делать
нечего.

## 4. Настройки

```bash
cp .env.example .env
nano .env
```

Заполняешь так:

```
BOT_TOKEN=            токен от BotFather, тот же самый
DOMAIN=               lyfeparty.duckdns.org
POSTGRES_PASSWORD=    новый длинный пароль, не тот что на макбуке
ADMIN_SECRET_KEY=     новый секрет
POSTGRES_HOST=postgres
ENV=prod
```

**`POSTGRES_HOST` обязательно `postgres`, а не `localhost`** — на сервере всё
работает внутри Docker, и обращение идёт по имени контейнера.

Сгенерировать пароль и секрет прямо на сервере:

```bash
openssl rand -base64 24
openssl rand -hex 32
```

Сохранение в nano: `Ctrl+O`, `Enter`, `Ctrl+X`.

**Смени `ADMIN_SECRET_KEY` относительно локального.** Он подписывает и сессии
администраторов, и токены в LYFE PASS. Локальные QR после этого на сервере не
подойдут — так и должно быть, гости получат новые.

## 5. Запуск

Все команды в проде идут с двумя файлами конфигурации. Чтобы не набирать
каждый раз, заведи короткий псевдоним:

```bash
echo "alias lyfe='docker compose -f /opt/lyfe/docker-compose.yml -f /opt/lyfe/deploy/docker-compose.prod.yml'" >> ~/.bashrc
source ~/.bashrc
cd /opt/lyfe
```

Поднимаем:

```bash
lyfe build
lyfe up -d postgres
lyfe run --rm bot alembic upgrade head
lyfe run --rm bot python scripts/seed.py
lyfe run --rm bot python scripts/seed_rewards.py
lyfe run --rm bot python scripts/create_admin.py max "пароль" SUPER_ADMIN
lyfe up -d
```

Проверяем:

```bash
lyfe ps
lyfe logs --tail=30 bot
```

Все контейнеры должны быть `running`, а в логах бота — `LYFE bot starting`.

### HTTPS

Caddy получает сертификат сам, обычно за десять секунд. Проверь:

```bash
lyfe logs --tail=30 caddy
```

Ищи слово `certificate obtained`. Если вместо этого ошибки — почти всегда
причина в том, что домен ещё не указывает на сервер. Проверь:

```bash
dig +short ТВОЙ_ДОМЕН
```

Должен вывестись IP сервера. Если пусто — подожди, DNS обновляется до часа.

Теперь открывай в браузере `https://ТВОЙ_ДОМЕН` — DJ-экран. И главное:
`https://ТВОЙ_ДОМЕН/scan` — **камера теперь работает**.

## 6. Останавливаем локальную версию

Один токен — один бот. Если оставить запущенным макбук, оба экземпляра будут
драться за обновления и оба сломаются.

На макбуке:

```bash
pkill -f "lyfe.bot.main"
pkill -f uvicorn
```

Локальная база с тестовыми данными остаётся нетронутой. На сервере база своя,
чистая — это правильно, тестовый мусор в бою не нужен.

## 7. Бэкапы

Дамп базы раз в сутки, хранение две недели:

```bash
crontab -e
```

Добавь строку:

```
0 5 * * * cd /opt/lyfe && ./deploy/backup.sh >> /var/log/lyfe-backup.log 2>&1
```

Проверь, что скрипт работает, прямо сейчас:

```bash
cd /opt/lyfe && ./deploy/backup.sh
ls -lh backups/
```

Скачать бэкап к себе:

```bash
scp root@IP_СЕРВЕРА:/opt/lyfe/backups/*.sql.gz ~/Desktop/
```

**Сделай это хотя бы раз вручную перед 22.09.** Бэкап, который никто не
восстанавливал, — это не бэкап.

## 8. Обновление после правок

С макбука пушишь в git, на сервере:

```bash
cd /opt/lyfe && ./deploy/update.sh
```

Скрипт сам подтянет код, пересоберёт образ, применит миграции и перезапустит
контейнеры.

Если заливаешь без git — сначала `rsync` с макбука, потом на сервере:

```bash
cd /opt/lyfe
lyfe build
lyfe run --rm bot alembic upgrade head
lyfe up -d
```

## 9. Что смотреть, когда что-то не так

```bash
lyfe ps                      # кто жив
lyfe logs -f bot             # логи бота
lyfe logs -f dj              # логи веб-части
lyfe logs --tail=50 caddy    # проблемы с сертификатом
lyfe restart bot             # перезапустить один сервис
lyfe exec postgres psql -U lyfe -d lyfe   # консоль базы
```

| Симптом | Причина | Что делать |
|---|---|---|
| Бот молчит | Контейнер упал | `lyfe logs --tail=50 bot` |
| `Conflict: terminated by other getUpdates` | Локальный бот всё ещё запущен | `pkill` на макбуке |
| Сайт не открывается | Сертификат не выдан | `lyfe logs caddy`, проверь `dig` |
| Камера не включается | Открыл по `http` или по IP | Только `https://домен` |
| `relation does not exist` | Миграции не применены | `lyfe run --rm bot alembic upgrade head` |
