# LYFE Mini App — запуск

Mini App живёт в том же веб-сервисе, что DJ-экран и сканер (`lyfe-web`), по адресу
`https://<домен lyfe-web>/app`. Отдельный сервис не нужен.

## Что поменялось

- **Mini App** — 4 вкладки: НОЧЬ, ТРЕК, TOP, MY LYFE. Бот остаётся: `/start`, кнопка
  `✨ ОТКРЫТЬ LYFE`, кнопка меню слева от поля ввода и `🎟 LYFE PASS` (QR в чате
  открывается без сети — на входе это важно).
- **Ссылки → текст.** Apple Music и Deezer ищутся точно по ID, Spotify — по превью
  страницы, YouTube/SoundCloud/TikTok — по oEmbed. Если ссылка не читается
  (Яндекс Музыка, VK, пустые страницы), просим прислать другую или написать название.
  Ссылка больше никогда не попадает в список как «трек».
- **Без дублей.** Ключ трека учитывает только главного артиста, транслитерацию
  (Макс Корж = Max Korzh), FE!N = fein, «- Remastered» и т.п. Плюс нечёткое
  сравнение внутри ивента: похожая запись присоединяется к существующей строке.
  В поиске видно «Уже в списке · 🔥 12 — присоединяйся».
- **BOOST** — 5 LYFE POINTS = +5 к треку в TOP, до 3 раз за ночь, на любой трек.
  На DJ-экране показан отдельно (`⚡ 10`), чтобы было видно платный спрос.
- **ГАРАНТИЯ** — как и была: 40 баллов, трек закрепляется у DJ, 2 на ночь.

## Деплой (Railway)

1. Задеплоить код. Миграция `a7d1e5b2c9f0` (колонка `boost_points`) применится сама
   при старте `lyfe-bot` (`scripts/start_bot.sh`).
2. В переменных **lyfe-bot** добавить:
   ```
   WEBAPP_URL=https://<домен lyfe-web>
   ```
   Без неё бот работает по-старому, только кнопками в чате.
3. Перезапустить `lyfe-bot`. В логах появится `Mini App at https://.../app`.

## +10 баллов всем

Сначала посмотреть, кому начислится (ничего не пишет):

```bash
railway run python scripts/grant_points.py --dry-run
```

Начислить и отправить сообщение в бот:

```bash
railway run python scripts/grant_points.py --notify
```

Повторный запуск никому не начислит второй раз (ключ `gift:back2lyfe-2026-09:<user>`).
Для нового подарка — новое имя: `--campaign <имя>`.

## Склеить дубли, которые уже есть в базе

```bash
railway run python scripts/merge_duplicates.py          # план, ничего не пишет
railway run python scripts/merge_duplicates.py --apply  # применить
```

Заявки и лайки переезжают на основную строку (человек, который был на обеих,
считается один раз), бусты и гарантия тоже. Начисленные баллы не трогаются.
