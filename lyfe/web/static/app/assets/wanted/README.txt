Фото организаторов для плаката «Разыскивается» на экране «Миссия».

1. Положи сюда 4 фото лица (jpg или png), лучше вертикальные, лицо в верхней трети.
2. В index.html найди const WANTED и впиши имена файлов в photo, а роли в role:
   { role: 'Диджей', photo: 'org-1.jpg' }
Экран сам кадрирует фото в 3:4 и делает его чёрно-белым.
